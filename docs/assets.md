# Veyrith assets

This directory contains the release-owned product assets used by the repository.

| Asset                             | Purpose                                                                                      |
| --------------------------------- | -------------------------------------------------------------------------------------------- |
| `brand/veyrith-mark.svg`          | Canonical scalable signal-knot mark for documentation, favicon work, and release collateral. |
| `screenshots/veyrith-desktop.png` | Full-page desktop workspace capture from the verified preview.                               |
| `screenshots/veyrith-mobile.png`  | Mobile viewport capture showing the responsive brief composer.                               |

The mark is an original Veyrith symbol. It is intentionally a simple geometric signal-knot rather than a copied wordmark or third-party logo.
